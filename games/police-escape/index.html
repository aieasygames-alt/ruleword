Police Escape Game Guide

📖 About

Police Escape is a turn-based chase puzzle rebuilt from the original game's extracted level configurations. Move Viktor one connected node at a time while police respond along the shortest available route. Collect every key, exploit portals and devices, and reach an open exit before the pursuit closes in. The game includes all 183 reconstructed node layouts and supports touch or mouse play.

🎯 Objectives

Reach an open exit before the police catch you. Collect every required key and use each level's devices to create a safe route.

🎮 How to Play

Select one of the glowing connected nodes to move. After every move, each active police advances one node along its shortest route toward you.

⌨️ Controls

Tap or click a glowing connected node. Use Reset to restart the current case.

⚙️ Game Mechanics

  • ▸ Viktor and police move one graph node per turn
  • ▸ Police use BFS shortest-path AI to chase you
  • ▸ Only directly connected nodes can be selected
  • ▸ Collect all keys before exiting

✨ Features

  • ★ 183 reconstructed original level layouts
  • ★ Keys, portals, ice, springs, spikes, bridges, shields, and dual exits
  • ★ Linear unlock progression
  • ★ Best step count per level

💡 Tips

  • ✓ Count graph edges — every extra move gives police another step
  • ✓ Use branches and portals to force police onto slower routes
  • ✓ Collect shields before attempting a risky crossing
  • ✓ Watch spike timing and which dual exit is currently open
  • ✓ Sleeping police wake when the chase gets close or keys are collected

❓ Frequently Asked Questions

How do police move?
Each active police computes the shortest path to your current node and advances one connected node after your move.
Why did I lose when our paths didn't overlap?
If the thief and a police trade cells in the same turn (thief moves into police's old spot while police moves into thief's old spot), that counts as a capture.
Are the levels solvable?
The game loads all 183 extracted layouts. Advanced device behavior is reconstructed from the available configuration schema and can be refined as more original method logic is recovered.
Does my progress save?
Yes, progress (unlocked levels and best step counts) is saved to your browser's localStorage. Clearing browser data resets it.
Can I replay earlier levels?
Yes. The level-select screen shows every unlocked level with your best step count, so you can revisit and improve.
